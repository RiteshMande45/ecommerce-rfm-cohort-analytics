# 📊 E-Commerce RFM Segmentation & Cohort Retention Analytics

An end-to-end data analytics project featuring relational database modeling in PostgreSQL, RFM customer segmentation, monthly cohort retention analysis, and an executive Power BI dashboard.

## 🚀 Project Overview
This project ingests, cleans, and structures retail transaction data (~397k records) into a robust star schema database, applies customer segmentation, and visualizes key business metrics.

## 🛠️ Tech Stack
* **Database:** PostgreSQL
* **Processing:** Python (pandas, SQLAlchemy)
* **Visualization:** Power BI Desktop
* **Version Control:** Git & GitHub
